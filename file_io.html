1. 開啟檔案 (open)

在 Python 中，與檔案互動的第一步是使用內建函式 open() 開啟檔案。它會回傳一個檔案物件。
每次開啟檔案後，最後都必須呼叫 close() 方法來關閉檔案釋放系統資源。

存取模式 (Mode)

開啟檔案時需要指定一個存取模式，告訴 Python 您打算對這個檔案做什麼：

  • 'r'：讀取模式 (Read-only)。預設模式。如果檔案不存在會引發錯誤。
  • 'w'：寫入模式 (Write-only)。如果檔案存在，會**覆寫**原內容；如果不存在，則建立新檔案。
  • 'a'：附加模式 (Append)。如果檔案存在，新的內容會被加入到檔案的**尾端**；如果不存在，則建立新檔案。
  • 'x'：互斥建立 (Exclusive creation)。建立新檔案，如果檔案已存在則引發錯誤。
  • 'b'：二進位模式 (Binary)。處理非文字檔案 (如圖片、影片)，例如 'rb' 或 'wb'。
  • '+'：更新模式。可同時讀取和寫入，例如 'r+' 或 'w+'。
# 開啟檔案準備讀取 (預設是 'r' 模式)
file = open("example.txt", "r", encoding="utf-8")

# 記得要關閉檔案！
file.close()

2. 使用 with 語句 (推薦)

手動呼叫 close() 很容易忘記，或者當程式發生錯誤時沒有執行到 close()。 在 Python 中，強烈建議使用 with 語句（這是一個上下文管理器 Context Manager）來開啟檔案。

好處： 在 with 區塊結束或發生例外狀況時，檔案會**自動被關閉**。 

# 使用 with 自動關閉檔案 (強烈推薦的寫法)
with open("example.txt", "r", encoding="utf-8") as file:
    # 這裡的縮排代表還在檔案開啟的狀態內
    pass  # 在此處對檔案進行讀取或寫入

# 當縮排結束，跳回原來的層級時，檔案會自動被關閉
print("檔案已經自動關閉了！")

3. 讀取檔案內容

開啟檔案 (使用 'r' 模式) 後，可以使用以下方法讀取裡面的內容。

  • .read()：讀取整個檔案的內容，回傳一個**字串**。
  • .readline()：每次讀取檔案的**一行**，回傳一個字串。
  • .readlines()：讀取所有的行，並回傳一個包含每行內容字串的**列表 (list)**。
# 準備一個範例檔案內容:
# 這是第一行
# 這是第二行
# 這是第三行

# 1. 讀取整個檔案
with open("example.txt", "r", encoding="utf-8") as f:
    content = f.read()
    print("--- 讀取整個檔案 ---")
    print(content)

# 2. 逐行讀取 (通常配合 for 迴圈使用)
with open("example.txt", "r", encoding="utf-8") as f:
    print("--- 逐行讀取 ---")
    for line in f:
        print(line.strip()) # strip() 可以消除每行尾端的換行符號

# 3. 讀取所有行並存成一個列表
with open("example.txt", "r", encoding="utf-8") as f:
    lines = f.readlines()
    print("--- 以列表形式讀取 ---")
    print(lines) 
    # 輸出: ['這是第一行\n', '這是第二行\n', '這是第三行\n']

4. 寫入檔案內容

要寫入資料到檔案，您必須以 'w' (寫入) 模式開啟檔案。
**注意：** 'w' 模式如果檔案已存在，原本的內容將會被完全清空並覆寫！

  • .write(string)：將字串寫入檔案。
  • .writelines(list)：將包含文字的列表寫入檔案中 (不會自動加上換行符號)。
# 寫入單行或多行文字
with open("output.txt", "w", encoding="utf-8") as f:
    f.write("Hello，這是新寫入的第一行！\n")
    f.write("這是第二行！\n")
    f.write("如果沒有加上 \\n (換行符號)，文字就會連在一起。")

# 寫入一個列表
lines_to_write = ["第一行資料\n", "第二行資料\n", "最後一行資料"]
with open("output2.txt", "w", encoding="utf-8") as f:
    f.writelines(lines_to_write)

5. 附加內容到檔案

如果您不想覆寫原來的檔案內容，而是想在現有的內容結尾處加入新資料，請使用 'a' (附加) 模式。 

# 假設 output.txt 已經有內容
with open("output.txt", "a", encoding="utf-8") as f:
    f.write("\n這行文字會被加在檔案的最結尾！")
    f.write("\n又加了一行！")

6. 讀寫 txt 檔案

讀寫 .txt 檔案是 Python 檔案處理中最基礎且常見的操作。我們通常會結合前面學到的 open() 函式與各種讀寫方法來處理純文字。 

# 1. 寫入多行文字到 txt 檔案
lines = [
    "第一行：這是純文字檔的內容。\n",
    "第二行：Python 處理文字非常方便。\n",
    "第三行：記得加上換行符號！\n"
]

with open("my_data.txt", "w", encoding="utf-8") as f:
    f.writelines(lines)
    print("成功寫入 my_data.txt，檔案內容已更新！")

# 2. 讀取並處理 txt 檔案的內容
print("\n--- 讀取 my_data.txt 的內容 ---")
with open("my_data.txt", "r", encoding="utf-8") as f:
    for index, line in enumerate(f):
        # 使用 enumerate 可以同時取得行號 (從 0 開始) 和內容
        # strip() 移除結尾的換行符號，讓輸出更好看
        print(f"第 {index + 1} 行內容: {line.strip()}")

7. 讀寫 CSV 檔案

CSV (逗號分隔值) 檔案非常常見於儲存表格資料。雖然您可以直接用一般的字串切割方式，但 Python 內建的 csv 模組處理起來更簡單穩健。 

import csv

# 1. 寫入 CSV 檔案
data = [
    ["姓名", "年齡", "城市"],
    ["小明", 25, "台北"],
    ["小華", 30, "台中"],
    ["小美", 22, "高雄"]
]

with open("people.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.writer(f)
    # 將巢狀列表寫入
    writer.writerows(data)
    
# 2. 讀取 CSV 檔案
with open("people.csv", "r", encoding="utf-8") as f:
    reader = csv.reader(f)
    for row in reader:
        print(row) # 每一列 row 都會是一個列表例如: ['小明', '25', '台北']

8. 處理檔案路徑

如果要開啟或建立的檔案不在目前的執行目錄下，您可以提供檔案的絕對路徑或相對路徑。使用 Python 內建的 os 或 pathlib 模組可以更安全跨平台地處理路徑。 

import os

# 取得目前工作目錄
current_dir = os.getcwd()
print(f"目前目錄：{current_dir}")

# 組合路徑 (自動處理 Windows/Mac/Linux 或雙斜線等問題)
file_path = os.path.join(current_dir, "my_folder", "data.txt")
print(f"目標檔案路徑：{file_path}")

# 檢查檔案或目錄是否存在
if os.path.exists(file_path):
    print("檔案存在！")
else:
    print("檔案不存在！")
