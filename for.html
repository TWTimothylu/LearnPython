PYTHON ・ FOR 循環

for 迴圈：讓重複工作變簡單

逐一取出資料，讓同一段程式幫你完成每一次任務。

學完後，你能……

  • 用 for 走訪清單與字串，解釋變數、冒號和縮排。
  • 用 range 控制起點、終點與步長，預測迴圈次數。
  • 在迴圈中累加與計數，正確處理空清單。

先備知識：變數、整數、字串、print() 與加法。清單用中括號包住資料、用逗號分隔，例如 [2, 4, 6]，空清單寫成 []。可先閱讀清單教學。

執行工具：使用課堂的 Python 3、Thonny 或 IDLE。複製程式到編輯器，逐筆替換資料、執行並核對輸出。本頁沒有 Python 執行器，勾選檢核不代表自動測試通過。

學習路線

01　逐一走訪資料02　range 數字範圍03　累加與計數

把重複工作交給 for

for 依序取出每個項目；縮排區塊每次執行一次。range 不包含終點。累加器在迴圈前設定、迴圈內更新，最終結果在迴圈後輸出。
