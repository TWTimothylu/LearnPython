PYTHON ・ 條件判斷

讓程式學會做決定

從一個 if 開始，依不同條件選擇不同的行動。

學完後，你能……

  • 使用比較運算與縮排，寫出只在條件成立時執行的程式。
  • 用 if／else 處理兩種結果。
  • 用 elif 安排多種結果，檢查門檻與判斷順序。

先備知識：變數、整數、字串和 print()。本頁使用直接指定變數的方式測試，不需要 input() 或迴圈。

執行工具：使用課堂的 Python 3、Thonny 或 IDLE。將程式複製到編輯器，執行後逐筆替換測試資料，核對輸出。本頁沒有 Python 執行器；勾選檢核不代表自動測試通過。

學習路線

把決策帶回你的程式

if 檢查條件，else 接住不成立的情況，elif 依序檢查其他條件。同一條分支鏈只執行第一個符合的區塊；冒號與縮排不能省略。
